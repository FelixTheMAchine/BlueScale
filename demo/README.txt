BLUESCALE DAs v0.4 — DEMONSTRAÇÃO OFFLINE

1. Abra index.html em um navegador (Chrome/Firefox/Edge).
2. Use as abas Início, Eventos, Equipe, Escala e Ajustes.
3. Clique em Gerar escala, revise vagas descobertas, altere turnos e exporte Excel.
4. Os 60 membros e todos os dados iniciais são FICTÍCIOS.
5. Alterações são salvas localmente no navegador, com opção Backup JSON.

IMPORTANTE: não é a versão web com login real ou equipes conectadas.
Este pacote permite avaliar fluxos e visual antes da publicação.
O pacote Android Studio que produz o APK está no arquivo BlueScale-DAs-Android-para-gerar-APK.zip.
